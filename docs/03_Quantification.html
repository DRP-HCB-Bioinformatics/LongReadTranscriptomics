Long Read Transcriptomics

For transcript quantification, again there are several tools that can be used. Some tools will need you to do transcript identification first (FLAIR), but there are many others that can work from mapped reads. These tools will need mapped reads, a reference genome sequence and a reference annotation. During this session we will take a look at Bambu, that can quantify reads on a transcript or gene level.

Bambu

In some cases, we specifically want to get counts per gene for a version of an annotation, without looking for new isoforms or transcripts. Though Bambu is capable of also identifying new isoforms and transcripts, mainly used organisms with a good annotation already present. In this case we will look at how to get counts for a specific annotation version.

To able to do this, we again need the mapped reads, a genome sequence and a genome annotation.

Bambu is based within R, a tool often used for different types of analysis. The first step that needs to be done is start R. Bambu needs one of the newest versions of R, which we have installed for you on the server.

R works from the current directory that you start R from. Meaning that it will have access to the data within the folder and will write to the folder if we create any files.

/library/training/LRT/R-4.6.0/bin/R

To be able to run commands for Bambu, the package needs to be installed within R. Packages are generally straight forward to install.

Note: You won’t need to run this when working on the server

BiocManager::install("bambu")

Once packages are installed, they still need to activated.

library(bambu)

To run Bambu, files need to be loaded. Multiple samples can be loaded at the same time. The larger the amount of samples, the longer the process will take. Running bambu on a server is advised to speed up the process.

files <- list.files(path="./", pattern="pacbio.chromosome2.bam$")

We can run bambu straight away. Bambu will prepare the annotation for easier access. If you use the genome often, the annotation can be prepared before hand and saved into an object to save time.

se <- bambu(reads = files, annotations = "../GCF_000001405.40_GRCh38.p14_genomic.gtf", genome = "../GCF_000001405.40_GRCh38.p14_genomic.fna", ncore = 12, discovery = FALSE)

Note: This will take several minutes

Once bambu is finished, we can write the output to a folder named bambu.

writeBambuOutput(se, path = "./bambu/")

Open up a new terminal to take a look at the resulting files. We want to keep the R session running to be able to continue working with the data later on.

Several files are generated, the most important are the files starting with counts. Bambu will generate files for both transcript level and gene level. Depending on the analysis, either file can be used.

Bambu has another great functionality which is to visualise genes and the different transcripts found for the genes plus the counts of the transcripts per sample. This can help visualise if you have specific transcripts that are being used between groups. Because we are working on a server, that means we cannot directly see the plots, however we can easily save them to a pdf file.

pdf("UGP2.pdf")
plotBambu(se, type = "annotation", gene_id = "UGP2")
dev.off()

The plot is by default saved to the current directory that is being worked in. The file can be downloaded from the server or you can view a prepared file here.

Because we have the data for all samples using PacBio, Nanopore Direct sequencing and Nanopore RNA sequencing, we have prepared a set of data which contain the results for all samples using bambu.

To load the data into R, run the following command.

seall <- readRDS(file="bamburesults_allsamples.rds")

To be able to create a pca plot which shows information on groups, group information needs to be added to the R object that we want to look at. Within bambu, information of samples is captures in colData(seall).
